# Formd for VS Code

扩展界面跟随 VS Code 显示语言，支持简体中文和英文，其他语言默认用英文。

从旧版扩展升级时，先关闭旧协作文档并停用旧扩展，再安装新版。VS Code 会把新版识别为独立扩展，需重新配置自定义服务器、显示名称和光标颜色。连接同一服务器后，从 Formd 侧栏重新打开文档可读取旧版草稿；最近访问记录会重新积累。

活动栏点击 **Formd 羽毛图标**，打开「协作文档」视图。

- 侧栏顶部：在根目录新建文档或文件夹、刷新列表、配置服务器。展开文件夹可浏览内容，右键文件夹可新建子文件夹或文档。
- 「最近访问」：保留最近打开或切换到的 20 篇文档，重启后保留，按服务器分别记录；顶部可清空记录。
- 点击文档：在 VS Code 原生 Markdown 编辑器中打开。
- 右键文档：重命名、移动、删除；行内按钮在 Web 中打开。右键文件夹可重命名、移动或删除空文件夹。
- 命令面板中的「Formd: 打开协作文档」支持按标题或路径搜索，最近访问优先。
- Markdown 预览：使用 VS Code 的「打开侧边预览」（Cmd/Ctrl+K V）。

设置 `formd.serverUrl`（默认 `http://localhost:3001`）与 Web 连接同一个后端。设置 `formd.webUrl`（默认 `http://localhost:5173`）用于浏览器打开文档。

正文通过 `@formd/y-vscode` 双向增量绑定到 Y.Text，**无需保存**，未保存状态也能和 Web 实时协作。支持多光标编辑、离线会话重连和当前客户端的 Yjs 撤销/重做（Cmd/Ctrl+Z，macOS Cmd+Shift+Z / 其他平台 Ctrl+Y）。远端更新应用时继续输入会重算增量，避免覆盖本地文字。

Ctrl/Cmd+S 只确认编辑器保存状态，不会再次把整篇旧快照写回共享文档。标题修改后刷新列表；打开中的文档保留原 URI，避免重复绑定。

打开协作文档时，状态栏显示「待同步」「已同步」「离线草稿」或「保存失败」。「已同步」表示服务器已确认持久化此客户端最新的修改。点击「保存失败」可重试。部署时需同步更新协作服务端，以启用保存回执。

开发：在仓库根目录运行 `pnpm run dev`，在 VS Code 按 F5 启动扩展开发宿主。打包运行 `pnpm run package:vscode`，安装生成的 VSIX。

这是无鉴权的单实例开发 MVP。VS Code 会在扩展的本地存储中保留当前服务器的协作草稿，重开文档后恢复，并在重连时与远端合并。可用「Formd: 恢复本地草稿」恢复协作或打开 Markdown 副本，也可用「Formd: 导出当前 Markdown」保存当前编辑器中的文字。切换服务器后，已打开的文档继续连接原服务器。升级后如果旧标签页无法恢复，可从 Formd 侧栏重新打开，或使用草稿恢复命令。

## 在线成员与光标

状态栏显示当前文档在线人数（含自己），点击打开成员列表，查看客户端和光标行列，再选择定位光标或跟随成员。跟随时状态栏显示成员名称，点击列表中的「停止跟随」结束跟随。跟随只滚动定位当前文档的远端光标；切换文档或键盘/鼠标操作自己的选区会停止跟随。

编辑器显示远端成员的彩色光标、姓名、选区及概览标尺位置，和 Web 使用同一套 Yjs 相对位置。设置 `formd.displayName` 修改显示名称，`formd.cursorColor` 修改颜色（留空自动分配）。

列表按当前文档的连接会话统计，并非已认证的用户账号。关闭文档即退出对应文档的在线会话；网络异常由心跳清理。当前只广播主选区，断线时清空远端成员，重连后重新注册。升级到 0.3.0 时应同时重启后端及 Web。
