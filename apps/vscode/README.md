# Typo for VS Code

活动栏点击 **Typo 羽毛图标**，打开「协作文档」视图。

- 侧栏顶部：新建文档、刷新列表、配置服务器。
- 点击文档：在 VS Code 原生 Markdown 编辑器中打开。
- 右键文档：重命名、删除；行内按钮在 Web 中打开。
- Markdown 预览：使用 VS Code 的「打开侧边预览」（Cmd/Ctrl+K V）。

设置 `typo.serverUrl`（默认 `http://localhost:3001`）与 Web 连接同一个后端。设置 `typo.webUrl`（默认 `http://localhost:5173`）用于浏览器打开文档。

正文通过 `@typo/y-vscode` 双向增量绑定到 Y.Text，**无需保存**，未保存状态也能和 Web 实时协作。支持多光标编辑、离线会话重连和当前客户端的 Yjs 撤销/重做（Cmd/Ctrl+Z，macOS Cmd+Shift+Z / 其他平台 Ctrl+Y）。远端更新应用时继续输入会重算增量，避免覆盖本地文字。

Ctrl/Cmd+S 只确认编辑器保存状态，不会再次把整篇旧快照写回共享文档。标题修改后刷新列表；打开中的文档保留原 URI，避免重复绑定。

开发：在仓库根目录运行 `npm run dev`，在 VS Code 按 F5 启动扩展开发宿主。打包运行 `npm run package:vscode`，安装生成的 `typo-vscode-0.3.0.vsix`。

这是无鉴权的单实例开发 MVP。离线修改尚未同步时请保持文档打开，或先复制/导出正文；断线草稿只存在会话内存中。切换服务器前请关闭当前协作文档。

## 在线成员与光标

「在线成员」视图列出当前文档的成员、客户端和光标行列。点击成员定位，点击行内图钉跟随，顶部停止按钮结束跟随。跟随只滚动定位当前文档的远端光标；切换文档或键盘/鼠标操作自己的选区会停止跟随。

编辑器显示远端成员的彩色光标、姓名、选区及概览标尺位置，和 Web 使用同一套 Yjs 相对位置。设置 `typo.displayName` 修改显示名称，`typo.cursorColor` 修改颜色（留空自动分配）。

列表按当前文档的连接会话统计，并非已认证的用户账号。关闭文档即退出对应文档的在线会话；网络异常由心跳清理。当前只广播主选区，断线时清空远端成员，重连后重新注册。升级到 0.3.0 时应同时重启后端及 Web。
